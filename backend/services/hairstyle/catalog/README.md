# Hairstyle catalog

Curated transparent PNG hairstyles used by `overlay.py`. This is a **manual asset** — add files here as they are prepared.

Naming: `<gender>_<style-slug>.png`, e.g. `male_textured-crop.png`, `female_long-layers.png`.

Each PNG should be front-facing, with a transparent background, roughly 1024 px tall, and include a small JSON sidecar (`<name>.json`) with anchor points (temples, hairline centre) for alignment.
